



```batch
1. 前端上传图片
    ↓
2. Controller: RecognizeImage(c *gin.Context)
    ├─ c.FormFile("image")  ← 获取上传的图片
    └─ image.RecognizeImage(file)  ← 调用 service 层
        ↓
3. Service: RecognizeImage(file *multipart.FileHeader)
    ├─ NewImageRecognizer(...)  ← 创建识别器
    ├─ file.Open()  ← 打开文件
    ├─ io.ReadAll(src)  ← 读取图片内容到 buffer
    └─ recognizer.PredictFromBuffer(buf)  ← 调用识别
        ↓
4. Common: PredictFromBuffer(buf []byte)
    ├─ image.Decode()  ← 解码图片
    └─ PredictFromImage(img)  ← 调用核心识别
        ↓
5. Common: PredictFromImage(img image.Image)
    ├─ 调整图片大小到 224x224
    ├─ 图片预处理（归一化、NCHW 格式）
    ├─ r.session.Run()  ← 运行 ONNX 模型推理
    ├─ 找出概率最大的类别
    └─ 返回类别名称
        ↓
6. 返回结果给前端
```
